Why NEXUS?

Problem

Scattered terminal tabs, duplicate workflows, and tools spread across machines.

Solution

NEXUS consolidates tools into one local, privacy-first terminal control panel so you can run and monitor everything from a single place.

Features

◈

NAS Manager

Monitor disk health, browse and sync files.

◉

Network Tools

Ping sweep your LAN, scan ports, and inspect devices.

⚿

Security Center

Parse intrusion logs and monitor SSH access.

▣

System Monitor

Live CPU, RAM, disk, and temperature charts.

✉

Email Tools

Send alerts and reports directly from NEXUS.

⬡

App Runner

Launch and manage Flask apps as background processes.

◎

Task Scheduler

Automate modules with recurring jobs.

⇄

NEXUS LINK

LAN-only peer-to-peer chat — no internet required.

◈

NEXUS ID

Local identity and login — no cloud accounts.

NEXUS in Action

$ git clone https://github.com/YOUR_USERNAME/nexus
$ cd nexus
$ python -m venv venv
$ venv\Scripts\activate  (Windows)  or  source venv/bin/activate (mac/linux)
$ pip install -r requirements.txt
$ python main.py

# Then open the NEXUS menu and select App Runner → Launch New App
